# OPC UA 本机验收（2026-10-21）

本轮在既有 LinkLab 工作目录实施 OPC UA，起始提交 `0d111b6`。原有 Vite、趋势图和 Rust 串口/持久化等11项改动已单独保存基线；本次没有改动原有数据库结构、应用 ID 或已安装配置。

## 验收范围

- 本地真实 node-opcua 服务器：None、Basic256Sha256、匿名与用户名认证，可写/只读/变化节点，64位整数、数组、ByteString。
- Electron 服务、Tauri 原生 harness、共享模型/组件及双端浏览器界面分别验收；不把 fixture 的显示测试作为原生协议证据。
- 回环网络与隔离数据目录。未知证书拒绝、核对后信任、安全连接、断线恢复、取消连接、过期会话、原子配置、导出上限均作为边界。

## 修复中发现的边界

- 并发替换订阅需要串行和会话身份保护；普通请求超时结束会话时需要通知界面解除连接状态。
- SDK 创建订阅成功不等于所有监视节点成功；任一节点创建失败，整组回滚并提示节点与状态。
- 保存、读取、导出配置采用一致的1 MiB上限，超限不能替换原文件。
- Electron IPC 不能发送 Vue Proxy，所有请求在共享模型边界转为普通 JSON 快照。
- Tauri native 命令遵循现有响应 envelope；加入 CLI 后显式保留桌面 default-run。
- 上游 async-opcua-crypto 只检查第一个 SAN 的 URI；维护最小补丁检查所有 URI 项，保留安全校验。
- Tauri SDK 在服务器正常关闭后会丢失恢复计划，原生层记录期望订阅并在重连后重建；旧回调取消。
- 空 String/ByteString 与空字符串不同；Matrix 与一维 Array 不同。双端保持 null 和 Matrix，矩阵只读。
- 无效的替换监视参数在共享模型先校验，保留原订阅及停止按钮；实际替换开始后失败，则清除监视指示。
- 重复 Tauri 首次启动发现间歇性连接超时，诊断确认 SDK 自动生成客户端证书时卡在本机主机名 DNS 解析。改为显式生成应用 URI 与回环 SAN，保留已有证书/私钥及服务器校验；不延长连接超时掩盖问题。
