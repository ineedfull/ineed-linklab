# LinkLab 0.1.1 测试版

发布日期：2026-11-20。

## 本版调整

- 修复串口读取与退出生命周期边界，改善关闭后窗口恢复及高负载消息渲染。
- 完善协议表单、设备模板与验收入口的一致性，整理 Modbus、分帧和持久化代码。
- 修复历史导出与保存边界，补充本机 WebSocket 双向收发[快速上手](../quick-start.md)。

## 安装与验证范围

从[官网下载页](https://linklab.ineedfull.com/downloads/)选择系统、CPU 架构及运行时，按页面列出的文件和构建标识下载。Electron 自带 Chromium，通常占用更多内存与磁盘。构建命令与矩阵见[打包指南](../desktop-packaging.md)。

本版按测试安装包分发，未配置 macOS Developer ID / 公证或 Windows Authenticode 正式签名。Windows Electron 包使用 Linux/Wine 交叉构建；生成文件不代表 Windows/Linux/macOS Intel 已全部通过实机安装升级验收。本批实际构建、摘要与运行检查以发布交接记录为准。

Tauri 的长期内存驻留仍有未完全归因的边界，不能把有限时长的改进当成所有泄漏均已排除，见[内存与退出复核](../reviews/2026-11-16-memory-and-exit.md)。

安装前退出应用，保留原应用身份和数据目录；完整备份先退出后复制用户数据目录。工作区导出不包含全部消息历史。本批不发布自动更新 feed。
