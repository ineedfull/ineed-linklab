# Modbus 从站自动变化

Modbus TCP / RTU 从站的“业务数据”工具栏提供默认关闭的“自动变化”开关和设置按钮。Electron / Tauri 使用同一套工作台实现。

1. 在端点配置业务数值点位，打开从站。
2. 点击“自动变化设置”，明确勾选要模拟的点位，并设置下限、上限、步长和统一间隔。
3. 保存设置后打开开关。每点从下限递增；下一值超过上限时回到下限。设置只保存规则，不会自动开启。
4. 关闭开关后保留当前数据，客户端仍可正常读取。再次开启从下限开始。

可选 uint16/int16/uint32/int32/float32/float64；ASCII、布尔字段不参与本轮变化。数值使用业务点位的缩放、偏移、字节序和字序进行编码；整数点位要求范围及步长能由整数寄存器表达，拒绝非有限数、越界及无法产生可表达变化的步长。从站本地模拟可改变标记为只读的点位；界面仍按既有规则限制手动编辑。

变化间隔为100～3600000毫秒，每轮写入完成后等待该间隔。它是桌面联调模拟器，定时器可能受窗口后台或系统调度影响，不提供实时采样保证。多个点位依次写入，每个点位的全部寄存器一次提交；跨点位没有整组原子快照保证。

## 生命周期与数据

- 定时任务归工作台模型持有。切换端点或页面后继续；每端点独立运行，同端点写入串行处理，不积压定时任务。
- 停止端点、会话变化、通信错误、点位配置变化、删除端点、导入/重置工作区或退出应用时停止；重新打开从站需手动启用。
- 自动变化时暂时禁用界面中的手动业务/原始值编辑，避免编辑冲突；设置仍可打开，保存会停止当前变化。
- 规则仅保留本次工作台会话；点位配置变化会清除旧规则。没有新增数据库结构或改写已保存的初始寄存器值。关闭/重开从站使用端点原初值。
- 已发送的本地写入可能在关闭开关后完成；停止后不再发送下一笔。两原生运行时检查 `expectedSessionId`，旧写入不能改变新会话。
- 写入失败时开关关闭并展示错误；不静默自动重启。

## 振弦联调示例

厂家14寄存器保持原布局，仅勾选 F（5000，float32）和温度（5002，float32）：F为5500～5510、步长0.5；温度27～29℃、步长0.25；间隔500ms。仪器编号、K、b和单位码不勾选。实际Qt/QSerialPort联调结果见独立Qt样板仓库 `docs/LINKLAB-INTEROP.md` 和工具工作区2026-11-05联调任务。

## 代码与验证

`packages/workbench/src/model/modbusSlaveSimulation.js` 管理规则、编码及有界调度；`ModbusSimulationControls.vue` 负责开关和设置；`createWorkbenchModel.js` 管理生命周期。原生 `modbus.writeMap` 复用既有接口，增加可选会话校验，旧手动调用保持兼容。

验证覆盖数值编码/范围/缩放精度、停止/重启竞态、多端点和卸载，Electron/Tauri入口的Chromium/WebKit浅深色、大字及折叠菜单，以及两原生运行时的旧会话写入拒绝。Qt独立联调使用实际Electron从站和macOS PTY，不代表实体RS485、Ubuntu/RK或Tauri完整原生GUI验收。
