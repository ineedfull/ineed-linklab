# OPC UA 模拟服务端双端对攻与压力验收

日期：2026-10-22。状态：本轮修复、原生异常、自动化回归和双端可见正式 20＋3 长跑验收完成。

## 范围与环境

本轮针对新 OPC UA 模拟服务端及其共享客户端。实际运行 macOS arm64 的品牌 Electron / Tauri 桌面，双方向同时互联；应用数据、Tauri 应用标识及回环端口均隔离。浏览器适配器测试、真实原生协议测试和真实桌面压力分别记录。

每端运行一个 100 节点 Server，并连接对端 Server：1 个共享工作台 Client + 3 个额外原生 Client，各订阅 100 节点、间隔 100ms。其中 96 个节点每 100ms 自动递增，4 个手动节点用于读写和保留项。正式阶段每 50ms 间隔发起一轮，3 个辅助 Client 各写入自己的节点，再各读取全部 100 节点；核对返回数量、质量以及自己的精确写入值。

因此每轮每端包含 3 次写、3 次读请求、300 个读取值质量检查和 3 个精确回读。轮次间隔不包含请求耗时，不能把配置的 50ms 换算成固定实测吞吐量。订阅通知可由协议采样合并；通知计数用于描述实际收到的数据，不宣称逐次自动变化全部投递。

正式计时前分别停止和重启两端 Server，验证自动连接和订阅恢复；负载中每约 4 分钟重连一个辅助会话。每约 30 秒检查 8 条流、96 个自动节点的新鲜度、Good 质量、1,000 条历史/200 行表格上限、实际前台面板、窗口可见性和同一个页面启动标识（另记录原始 timeOrigin）。停止负载后核对全部流最终 3 个手动值，再断开客户端并停止服务，保持原进程静置 3 分钟；不用 GC、重载或重启替代恢复。

## 本轮修复

1. 共享/Rust 对非法 `simulation` 接受范围与 Electron 不一致。显式配置必须为对象，手动/翻转模式中出现的数值参数也必须有限；省略或空对象仍兼容默认值。
2. Electron SDK 默认握手保留 180 秒。模拟服务端显式设为 5 秒，避免静默/部分 HEL 长时间占用额度；通用客户端配置保持原有语义。
3. 高频订阅原先逐项移动 1,000 条响应式历史，真实 WebKit 面板曾持续高 CPU 并超时。改用普通有界 Map/环形历史，每 50ms 批量发布；读取、导出和会话结束同步刷新，清空、重连、销毁不恢复旧事件。

4. 实时表格使用自动列宽，值/质量码/时间长度变化导致列反复伸缩。客户端、服务端均使用固定布局和显式列宽、等宽数字；窄窗口保留横向滚动。浏览器几何回归先出现 12/12 失败，再 12/12 通过；真实双端四张表各 100 次采样均无列位移。
5. Rust SDK 的订阅调度提前访问待采样值后丢失其调度 ID，最后一次写入能 Read 到但订阅收不到。基于原 0.19.0 保留最小 vendor 修补，区分等待采样与就绪通知；到期重新调度，同时保持正常保活，删除/替换/清空监控项时清理。保留原始 25 组连续写入末值回归失败和通过，以及保活状态机红绿证据。独立复核通过。

红绿证据、原始失败及最终原生报告保存在工作区证据目录。校准中另修正脚本的 Vue 勾选更新等待与窗口筛选：macOS 的隐藏菜单栏表面不能视作工作台窗口。它们是测试脚本问题；不修改产品窗口行为。

## 发布与适用边界

本轮无新增提交、安装包、签名、上传或网站发布。现有公开下载包及上一轮准备的四个 macOS DMG 都早于新 Server，不包含本轮功能。当前模拟 Server 仅支持 None/匿名；Client 的安全能力不能写成 Server 的安全能力。

本机双端回环结果不能替代 Windows/Linux/macOS x64 安装、真实远程设备、生产安全或长期现场验收。RSS 与 macOS footprint 分开报告，基线已包含初始化和订阅，不属于冷启动内存；进程同样承担 Server 与 Client，不能作为单独 Server 的性能结论。有限时长测试不能排除所有内存泄漏。
