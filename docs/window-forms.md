# 窗口参数与分组约定

Electron / Tauri 共用工作台组件。字体、主题、选择框继续遵循 `typography.md`；窗口表单的公共样式维护在 `packages/workbench/src/styles/dialog-forms.css`。

## 工作区工具入口

侧栏底部“工具箱”统一收纳跨端点的辅助任务：数据处理组提供“编码与校验”，工程调试组提供“设备模板”和“验收检查”。端点列表保留连接资源及其操作。菜单在展开与折叠侧栏均可使用，支持方向键、Home/End、Escape、Tab 与点击外部关闭；辅助窗口关闭后焦点返回常驻的工具箱按钮，保留通信草稿和后台会话。菜单使用独立浮层，避免被侧栏滚动与 overflow 裁剪。

## 参数顺序

先确认编辑对象，再填写连接或读取范围，最后调整调度、恢复和可选策略。名称、长地址和 JSON 应提供足够宽度；地址与端口、起始地址与数量、上下限等成对参数放同一行。普通与大字模式都检查实际控件边线，不能只检查标签容器。

| 窗口 / 区域 | 从上到下的顺序与分组 |
| --- | --- |
| 新建 / 编辑端点 | 名称 → 类型 → 连接参数 → 协议参数与运行策略。各协议保持同一窗口尺寸；串口参数结束后，Modbus 参数单独起组。 |
| TCP 客户端 / 服务端 | 地址、端口 → TCP 连接与接收。Keepalive / 客户端自动重连集中排列，探测延迟与输入行对齐；分帧方式与对应参数同行。原始模式没有额外参数时占整行。 |
| WebSocket 客户端 / 服务端 | URL 或监听参数 → 子协议 → 默认消息类型及客户端重连、心跳选项 → 心跳间隔 / 超时 → 临时请求头。服务端不提供客户端重连选项。 |
| Modbus 主站 | 传输参数 → Modbus 参数 → 主站调度与恢复。名称 / 说明整行；启用、自动轮询及 TCP 断线重连集中呈现。 |
| Modbus 从站 | 传输参数 → Modbus 参数 → 从站数据区 → 业务数据点。重复的数据区 / 点位保留各自内容结构。 |
| DL/T 645 主站 / 模拟器 | 串口参数 → 抄读或模拟策略。配置页电表名称、地址与启用控件保持输入行对齐；数据项与报文诊断保留独立视图。 |
| 请求组 | 名称整行 → 从站号与启用 → 说明整行。简单表单按内容决定高度。 |
| 读取请求 | 基本信息 → 读取范围 → 轮询与恢复 → 数据点。地址 / 数量、周期 / 超时、重试次数 / 间隔分别成对排列。 |
| 请求数据点 | 名称与唯一标识 → 偏移 / 类型 / 数据顺序 → 换算、单位与质量范围 → 历史采集。最多四列；名称与唯一标识各占半行，窄窗口减少列数。 |
| 写入指令 | 名称、说明、启用 → 写入目标（功能码、从站号 / 地址）→ 写入值与校验反馈。 |
| 设备模板 | 提取模板 → 模板内容与版本 → 新建现场实例 → 可折叠的导入工具。实例名称整行，类型 / 站号、地址 / 端口、波特率 / 校验分别成对排列。 |
| 验收检查 | 保存方案选择 → 方案名称 → 协议 / 目标 → 检查项 → 检查参数 → 执行、结果与导入导出。检查名称整行，地址 / 数量、范围上下限成对排列。 |
| 设置 | 运行设置 → 显示设置 → 工作区 → 数据存储。保留草稿、取消 / 放弃修改和错误反馈；分节标题足以表达层级，无需再套一层框。 |
| 关于 | 产品身份 → 版本与运行时 → 官网与数据说明 → 关闭。展示型内容使用描述列表。 |
| 工具箱 | 分类 / 当前工具 → 计算参数 → 输入 → 计算与示例 → 输出。保留工具特有参数，不强行拆分只有一两个字段的表单。 |
| 消息 / 日志历史 | 查询条件 → 列表 → 所选记录详情 → 分页。筛选控件提供明确的可访问名称。 |
| OPC UA / STOMP 工作台 | 连接配置、安全认证、节点 / 订阅、消息 / 值编辑按任务分区。服务端配置名称、路径和命名空间整行；现有独立滚动区域保持可用。 |
| 原始数据抽屉 / 消息详情 / 发送资料库 | 保留列表、详情及上下文命令结构。单项编辑和只读详情不额外堆叠 fieldset。 |

## fieldset 与窗口外壳

- 使用 `fieldset` / `legend` 表达相关参数，配合 `.dialog-form-section` 的标题与细分隔线。组内控件沿用外部网格边线，不再通过边框内缩一层。对整段表单使用 `disabled` 的 fieldset 是交互保护，不等同于业务分组。
- 单纯的说明、结果、列表、状态和已有分节面板使用 section、标题或描述列表；重复的设备数据卡片可以保留边框以区分对象。
- 相关勾选项集中呈现；与输入框同行时锚定输入行，不随校验说明移动。普通 / 大字控件高度为 32 / 36；协议内已有紧凑表格按自己的尺寸检查对齐。
- 端点配置的 `.endpoint-config-dialog` 为 880 × 760 的上限，受可用视口约束。固定标题、正文滚动、底部取消 / 保存；切换协议不改变外框位置。
- 其他编辑窗按内容确定高度，不继承端点配置固定高度。设置、关于、工具箱、模板、验收及抽屉沿用各自任务所需的宽度上限；操作顺序、留白和滚动行为保持一致。
- 只有显式选择的辅助内容使用 details；必填字段、错误和影响当前动作的提示保持可见。

## 验证入口

在源码仓库运行：

```sh
npm run lint
npm run build
npm run test:components -w @ineed-linklab/workbench
npm run test:e2e -w @ineed-linklab/workbench -- -c playwright.form-layout.config.js
```

`dialog-sections.spec.js` 验证参数配对、整行名称、协议切换外框稳定及简单窗口高度；现有 form / expanded-form 覆盖主题、字号、侧栏、宽窄窗口、错误态、历史筛选、编辑器与键盘滚动。`workbench.spec.js` 覆盖电表配置勾选项与实际抄读流程。模板、验收、工具箱和关于等业务流程继续使用各自既有 E2E。

浏览器 fixture 只证明共享界面；原生数据保存、协议交互与安装包启动须单独记录，不能以打包目标或截图推定其它平台已验收。
