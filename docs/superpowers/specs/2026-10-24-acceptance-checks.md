# LinkLab 可重复只读验收检查

日期：2026-10-24。用户已批准按工程联调、验收和交付方向直接实施，本轮完成首个可使用闭环。

## 结果与边界

侧栏“验收检查”打开共享面板。用户建立 Modbus 或 OPC UA 检查方案，绑定一个已连接的客户端/主站端点，执行有序读取、比对期望，保存当次方案快照、实际结果、时间和错误，导出 JSON/Markdown。支持再次执行和停止。无自动连接、扫描、脚本执行或写设备操作。关闭面板不中断运行。两运行时共享领域逻辑及界面。

## 数据与判断

方案：`{id,name,protocol,checks}`，protocol 为 modbus/opcua；checks 每项 `{id,name,query,assertion}`。
Modbus query：`{unitId,functionCode,address,quantity,timeoutMs}`，只允许 FC1/2/3/4、合法协议地址/数量和 100～30000ms 超时。实际值为数组；界面明确地址从 0 开始。
OPC UA query：`{nodeId}`；直接发起当前连接的新读取，不使用订阅缓存。值保留 Boolean/数值/字符串/数组等真实类型，Int64/UInt64 十进制字符串不得转 Number。质量非 Good、响应缺失或读取失败一律失败。
断言 `{kind:'equals',expected:<JSON>}` 为严格 JSON 深相等，或 `{kind:'range',minimum,maximum}` 为有限 number（Modbus 一元素数组允许取唯一元素）、闭区间，不隐式转换字符串/Boolean。
方案最多 50 个、每方案最多 25 项、方案 JSON 最多 64 KiB。结果单项实际值/证据有界，过大应明确失败，不截断后判断通过。报告最多保留 20 份、单份最多 512 KiB，总工作区最多 2 MiB；超过总量先移除最旧报告，方案/最新报告不可静默丢失。报告包含唯一 ID、方案快照、端点名称/协议/身份、会话、开始/结束、本次整体结果和每项 passed/failed/not-run。不得存认证信息。内部时间为毫秒时间戳，界面/Markdown 使用现有统一本地时间格式。

## 执行与生命周期

捕获端点和会话；每次请求前后核对，重连、删除、导入不允许旧请求的结果冒充新会话通过。Modbus 通过现有 executeImmediate 调度，避免绕开请求顺序。顺序执行，普通断言失败可继续；会话失效及停止取消后续项。停止后在途结果不能变成通过，原生调用未结束时不能启动另一次运行。原生退出先停止并保存当前报告，再参与现有 shutdown 握手，不等待无界的网络读取。

## 保存、文件与界面

复用 SQLite settings，不修改已有迁移/应用 ID/数据位置；独立设置键与已有设置写入共用队列，外观保存不覆盖验收数据。原生边界限制持久化数据大小/类型；领域层严格验证导入和保存。损坏数据明确报错，不自动覆盖。保存失败保留编辑和报告并支持重试。方案可 JSON 导入/导出；导入先全量验证再加入，生成新 ID，不覆盖旧方案。原生导出只接受固定文件名，Renderer 不指定文件系统路径，取消保存不提示成功。
界面提供方案列表、名称/协议、检查列表与编辑器、已连接端点选择、保存/删除/导入导出、执行/停止、报告列表/详情。执行时锁定影响方案的编辑，结果与当前编辑稿分离显示；按主题/字号/侧栏折叠和窄窗口检查，不让 footer 按钮换行挤压。

## 验收

领域测试覆盖非法写功能码、范围/类型、快照、坏质量、取消、会话变更、重复执行、持久化竞态、导入失败不破坏旧数据。组件覆盖实际表单、错误和报告。双端浏览器覆盖主题/字号/窄窗口；本机真实 Electron/Tauri 经原生协议在 localhost 执行 Modbus/OPC UA 至少一个通过及一个失败，验证保存重载及停止。记录浏览器与原生区别。Windows/Linux 仅构建配置不宣称原生验收。本轮不打包、不上传、不改网站。
