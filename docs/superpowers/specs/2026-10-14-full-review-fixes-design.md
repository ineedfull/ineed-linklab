## L1–L4：原生与数据

L1：Electron Modbus FC15 对未配置地址返回 Illegal Data Address（02），不改任何线圈。正常批量写入全部完成后才返回成功；TCP 与 RTU 共用相同保护。不删除批量 hook 后用逐位修改规避原子性；不直接修改 node_modules，不升级依赖作为修复替代。

L2：Electron 原生历史写入重试耗尽/队列溢出须留下有界失败摘要，显式 flush/query/close 应能检测失败，应用内显示历史保存不完整。后台定时/达到批量上限触发不能产生未处理 rejection。重试与队列继续有界，后续新批次可保存，退出仍能清理资源；不承诺已丢批次可恢复，不以错误日志写入同一失败队列造成递归。

L3：双端工作区导入预检覆盖完整 transport 枚举；非法值在关闭活动连接之前拒绝，数据库不变，正常导入仍 close→flush→事务。沿用实际 schema/配置校验与 SQL 约束。

L4：Electron TCP client/peer 正常 EOF 或用户关闭前输出 delimiter/fixed/idle 残留、刷入事件/历史后清理；两端正常关闭语义一致。超限/不可信输入导致的终止继续整帧丢弃，不输出被截断的超限内容，不重复尾帧，不混入新会话。

## L5–L7、L10：协议数据与编辑

L5：有符号 BCD 在舍入后检查最高字节符号位占用。3 字节/4 小数幅值 79.9999 合法，正负 80/89.1234 不可表示并拒绝，正负合法边界正确往返。

L6：DL/T 模拟器保存捕获草稿 revision；保存期间继续编辑保留 dirty，旧成功不清除新编辑，旧失败不覆盖新会话/视图状态，用户可再次保存。

L7：Modbus 请求地址/数量/站号和 DL/T 模拟值/长度/小数位，先验证显式原始草稿，再归一化。空值、非整数或非有限值明确拒绝；旧配置缺省字段继续补默认值。拒绝不得发出 save 或发送错误请求，修正后可正常保存。

L10：DL/T 完整候选校验失败后重新搜索后继起始符，不信任损坏的长度跳过后继完整帧；保留半帧残留与既有校验/噪声恢复，解析工作与残留有界。可选 `resynchronizing` 状态随 remainder 跨分片保留，由主站组件与模拟器控制器消费，并在断连、会话替换或释放时清零。已知坏帧内的伪长头不得阻挡后继合法帧；普通真实半帧保持原行为。

## L8、L9、L11、L12：工作台

L8：Modbus 分类包含 modbus-tcp-master/slave、modbus-rtu-master/slave，其他分类与名称搜索照常工作。

L9：实时内容搜索能匹配实际原生 bytes 的 UTF-8 正文、HEX 与界面显示的 peer 地址；保持方向/来源等已有筛选，不把不存在的 text/remoteAddress 字段作为唯一依据，避免每次展示全量巨型载荷复制。

L11：连续模板删除不能留下已删除的可载入行。按端点/ID 管理完成，并保护尚未返回的列表快照；同一模板的重命名/删除按顺序执行存储和 UI 发布，不能被迟到成功结果恢复。不同 ID 可并发，不干扰关闭/切换端点的 generation 保护，失败仍可重试。

L12：在共享发送命令边界对逻辑 payload 应用 framing 恰好一次；native 接收已编码的 wire bytes。none 原样；line 在末尾没有 LF 或 CR 时追加 LF（0A），已有 CR/LF/CRLF 保持不重复；length-prefix 为 4 字节无符号大端 payload 字节长度（不含头）。UDP datagram 保持原字节。追加 CRLF 先做逻辑内容编码，line 不再重复追加。text/HEX/JSON 和单次/定时发送共用同一规则；模板、发送历史仍保存逻辑 bytes 与 framing，载入后不叠加前缀。现有 DL/T 主站和模拟器已组帧发送使用 `dlt645` 标记，须原样透传并保留原生目标/会话及历史元数据；其他未知标记拒绝。原生描述仅包含 endpointId/bytes/target/framing，不能泄漏逻辑 format。合法输入不得因编码改变导致旧会话结果回写新界面。记录分帧规则供用户配置对端。

该 LF/4 字节前缀定义属于修复既有未生效选项的必要实现选择。用户已授权修复；不另行增加确认门禁。若对端期望其他前缀格式，需要按产品规则配置或使用 HEX 内容，不在本轮扩展可选前缀系统。
