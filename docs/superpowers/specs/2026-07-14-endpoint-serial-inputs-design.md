# 端点名称与串口输入改进设计

## 目标

- 新建端点时不再要求用户输入名称，由端点协议和关键连接参数自动生成。
- 编辑端点时保留名称编辑能力，避免覆盖用户设置的业务名称。
- 串口波特率保留常用预设，并允许输入预设列表之外的正整数。
- 串口校验位和流控选项使用明确的中英文技术名称。
- Electron 与 Tauri 保存相同的数据结构并执行一致的前置校验。

## 自动名称

新建端点对话框不显示名称输入框。保存时根据最终配置生成名称：

| 传输类型 | 名称格式 | 示例 |
| --- | --- | --- |
| 串口 | `SERIAL_<端口>` | `SERIAL_COM3` |
| TCP 客户端 | `TCP_CLIENT_<地址>_<端口>` | `TCP_CLIENT_192.168.1.10_9000` |
| TCP 服务端 | `TCP_SERVER_<监听端口>` | `TCP_SERVER_9000` |
| UDP 客户端 | `UDP_CLIENT_<目标地址>_<目标端口>` | `UDP_CLIENT_192.168.1.10_9000` |
| UDP 服务端 | `UDP_SERVER_<本地端口>` | `UDP_SERVER_9000` |

串口名称只取路径最后一段，例如 `/dev/ttyUSB0` 生成 `SERIAL_ttyUSB0`。名称中的空白和不适合显示的分隔字符统一替换为下划线，连续下划线合并，并限制在 80 个字符以内。

名称冲突按不区分大小写比较当前端点列表。若名称已存在，则依次追加 `_2`、`_3`，直到名称可区分；追加后缀时仍保证总长度不超过 80 个字符。

编辑已有端点时显示名称输入框，并保持当前名称。编辑连接参数不会自动重命名端点。

自动名称由共享模型中的纯函数根据端点草稿和现有名称集合生成。对话框先校验协议配置，再生成名称并调用现有保存命令；Electron、Tauri 后端不各自复制命名逻辑。

## 自定义波特率

波特率选择框保留当前常用预设，最后增加 `自定义...`。选择该项后显示数字输入框。

- 只接受 `1` 到 `4294967295` 之间的整数，以 Electron 和 Tauri 的共同数据边界为准。
- 保存的数据仍为 `config.baudRate` 数字，不增加模式字段。
- 编辑已有串口端点时，预设值选中对应选项；非预设值自动进入自定义模式并回显原值。
- 操作系统或串口驱动拒绝某个波特率时，由打开串口操作返回明确错误，不静默替换成其他值。

## 选项文案

校验位显示为：

- `无（None）`
- `偶校验（Even）`
- `奇校验（Odd）`
- `固定 1（Mark）`
- `固定 0（Space）`

流控显示为：

- `无（None）`
- `硬件（RTS/CTS）`
- `软件（XON/XOFF）`

选项值和持久化结构保持不变。

## 能力边界

Electron 当前支持 `Mark`、`Space` 和 `1.5` 停止位。Tauri 使用的 `serialport 4.9` 当前不支持这些值，仍必须返回明确错误，不能静默降级。本次改动不更换 Tauri 串口库，也不改变该能力边界。

## 验证

- 模型测试覆盖预设和自定义波特率的合法、非法边界。
- 组件测试覆盖新建自动命名、名称冲突后缀、编辑名称保留和自定义波特率回显。
- 组件测试覆盖新的校验位与流控文案。
- Electron 与 Tauri 原有串口配置和持久化测试继续通过。
- 浏览器检查桌面和窄窗口下，自定义输入出现时不挤压或覆盖其他字段。
