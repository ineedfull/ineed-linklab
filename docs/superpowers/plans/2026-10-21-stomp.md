# STOMP Client / Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Both desktop runtimes expose a practical STOMP 1.2 client and local test broker.
**Architecture:** Shared protocol/workbench and Vue panel over a dedicated ephemeral native WebSocket bridge. Native bridge never enters existing transport persistence; all STOMP logic is shared.
**Tech Stack:** Vue, existing Node ws/Rust tungstenite, shared JavaScript, optionally @stomp/stompjs for proven client implementation and interoperability.
**Spec:** `docs/superpowers/specs/2026-10-21-stomp-design.md`

## Global Constraints

Preserve all existing changes; no commits/publish; in-place source. Exact API/limits/security and exclusions in spec are binding. Keep long-running GUI evidence isolated from new source builds. Do not change existing transport history behavior.

### Task 2: Shared STOMP protocol and controller

Files: `packages/workbench/src/model/stomp*.js`, corresponding `packages/workbench/tests/stomp*.test.js`, dependency manifests/lock if using SDK. Own only these model/test/dependency files.
Interfaces: createStompWorkbench API and native bridge above. Config defaults client `{url:'ws://127.0.0.1:61614/stomp',host:'localhost',autoReconnect:true,heartbeatOutgoing:10000,heartbeatIncoming:10000}`, server `{listenHost:'127.0.0.1',listenPort:61614,path:'/stomp',host:'localhost'}`. credentials `{login:'',passcode:'',headers:[],requireAuthentication:false}`. subscriptions rows `{id,destination,ack}`. send request `{destination,body,contentType:'text/plain',receipt:true}`. ack/nack accepts displayed message id. saveProfile persists safe whitelist `stompProfiles` setting.

- [ ] Write real parser/broker tests for content-length Unicode/NULL, split/multiple frames, header escaping, version/host/auth rejection, topic broadcast/queue distribution, ACK cumulative/individual, NACK redelivery, receipt and bounds; observe RED.
- [ ] Implement bounded codec and test broker; use mature client SDK or small well-tested shared client with negotiated heartbeat/recovery. Adapter uses ephemeral native bridge and fences old events by connection/session; serializes writes and keeps queues bounded.
- [ ] Implement controller with safe profiles, errors, limits, subscription restoration, disconnect cancellation and no outgoing auth records. Test reconnect/heartbeats and sensitive data exclusion using real wire fixture and controlled clock where useful.
- [ ] Run `node --test packages/workbench/tests/stomp*.test.js`, scoped eslint. Return API example and RED/GREEN evidence for UI integration, never commit.
