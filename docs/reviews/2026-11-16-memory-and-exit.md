# LinkLab 内存、串口读取与退出复核

## 范围与证据

2026-11-16，macOS 27.2.1 arm64、Electron 43.1.0、Node 26.13.0、WebKit 22625.2.8.11.9。源码基于 main `1df2099`，保留进入任务前的 13 个 Review 修复文件；本轮未提交、推送或发布。所有通信使用回环地址、socat PTY 和隔离 SQLite。

证据在工具工作区 `scratch/2026-11-16-linklab-memory-exit/`。自然资源观察不打开 WebKit Inspector 或 DevTools、不采集会触发 GC 的 JS 堆快照、不强制 GC、不重载或重启来制造回收；Electron 通过 Playwright 自带的调试连接驱动。`heap` / `vmmap` 是原生采样，采样本身可能短暂停顿进程。RSS、physical footprint 与 malloc 活跃字节分别记录，不能混用或相加。

## 修复

### Darwin Modbus 读取不依赖共享线程池

旧实现通过异步 `fs.read` 读取已按 `O_NONBLOCK` 打开的串口描述符，仍需进入 libuv 共享线程池。用真实 PTY、独立 Node 进程和四个占满线程池的后台任务，确认原读法在 600ms 内收不到已到达的输入；改用单次非阻塞 `fs.readSync` 后通过。空读继续等待 2ms，不忙循环，关闭后的身份检查、取消和断连错误处理仍生效。

依赖的 bindings-cpp Unix open 使用 `O_NONBLOCK`，setup 未清除此标志；该约束是同步读取可用的前提。升级串口 binding 时必须重新核对。没有替换原生 open/close/write，没有全局补丁。

这证明并消除了读取对共享线程池的依赖，**不能据此认定它是历史 `CleanupHandles → uv_run/kevent` 挂起的唯一根因**。

### 实时消息按视口渲染并复用行

保留原消息留存与落盘行为；最多 500 条展示数据继续可滚动访问。超过 40 条且容器有可测量高度时，仅挂载视口及上下 160px 范围的行，并复用可见行槽位，避免每条消息创建整套 DOM。短列表保持原有消息身份。

行高通过 ResizeObserver 测量，在 RAF 中更新几何；暂停阅读时，留存淘汰和行高变化按消息身份恢复锚点。组件卸载时断开观察器、取消 RAF 并清空测量映射。复制、详情、来源和反馈始终取当前行数据。

第一次仅缩减可见 DOM、仍逐消息创建组件的方案并未改善本轮内存：第一轮结束 WebContent footprint 669.96 MiB，第二轮结束自然回到 336.94 MiB，RSS 仍约 1416 MiB。该中间证据完整保留，不能当作最终优化成功的依据。

### WebSocket 二进制预览

压力消息交替包含文本和以 `FF 00` 开头的二进制。事件已标注 BIN，但列表原来默认按 Text 解码，`FF` 变成替代字符 `�`。现在未指定显示格式的 BIN 默认 HEX，TXT 默认文本；详情显式选择 Text / JSON / HEX 仍有效。复制完整内容采用同一默认规则，原始字节和数据库不改写。

## 回归与原生结果

基础回归：完整 Node 测试 1380 通过、组件 364 通过；随后补充行高锚点回归，相关组件 12 通过。最终 lint、两套 renderer 构建及浏览器 12 项通过。浏览器覆盖 Electron/Tauri 两个入口、三尺寸与浅深色/普通大字/两种密度/侧栏展开折叠，验证滚动、尾项、复制、详情和暂停恢复；实际截图已人工检查。浏览器入口是桥接 fixture，与原生验收分开。

### 原生 WebSocket 基线与中间方案

基线：553 个循环，双端各 70,784 条数据库帧，300.277 秒负载及 180 秒分段静置，总 484.474 秒。完整字节、序号、跨端收发顺序及数据库完整性通过。

中间方案：同进程两轮各 553 个循环，共 1106 个循环、双端各 141,568 帧，总 853.148 秒；6 次重连、24 次非法输入拒绝，完整内容/序号/跨端顺序和数据库完整性通过。结束阶段只挂载 13 行，清空后 0 行；每次采样检查窗口可见、未最小化和屏幕未锁定。没有用重启实现第二轮恢复。

本机所有测试子进程继承 Codex 的 responsible PID，旧资源 helper 的宿主归属过滤会漏掉 WebContent。另保存全进程原始采样，通过该隔离运行唯一新 WebContent PID 识别目标；不能把原 helper 仅包含宿主的结果当作 Tauri 总内存。

### 原生 RTU 持续通信与退出

真实 Electron 与独立 Node Modbus 主站通过 socat PTY 通信 1,200,245ms，完成并核对 14,277 笔事务。主站正常关闭，Electron 关窗后通过 activate 恢复一个可见窗口，最后约 103ms 正常退出，exit 0、无终止信号。读取/事务在整个采样区间持续推进，没有用强杀完成本轮退出。

该运行恢复了窗口可见性，但没有覆盖每一秒的桌面解锁和遮挡；不能把“启动为可见窗口”扩写为完整前台验收。

## 边界

原退出基线运行约 315 秒后停止收发，但事件显示 `window-all-closed` 先发生、会话已清空，sample 在正常 AppKit 循环，未见历史 CleanupHandles 堆栈。触发关窗的来源未确认，不能将它作为旧挂起的成功复现。

原生堆中看到 WebCore Text/DOM、JSC StringSourceProvider 与大量尚未分类的 non-object 分配。未取得全部分配调用栈；不能将所有剩余占用称为缓存，也不能仅凭 RSS 未下降认定持续泄漏。上述版本和有限负载不能替代 Windows/Linux、实体串口或数日运行验收。

## 最终方案原生复核

最终构建包含行槽位复用、阅读锚点和二进制显示修正。双端 553 个循环、各 70,784 帧，负载 236.845 秒、分段静置 180 秒，总 421.628 秒。3 次重连、12 次非法输入拒绝；完整字节、独立序号、跨端顺序与 SQLite 完整性均通过。两端原生 DOM 的 BIN 预览均以 `FF 00 44 31` 开始，通过明确断言。

通过 `NSRunningApplication.terminate` 向本轮隔离 Tauri 宿主发正常退出请求，约 467ms 后原宿主确实消失；Electron 也正常关闭，脚本 exit 0。所有本轮记录的宿主、launcher 和 WebContent PID 已核对退出，PTY/socat/caffeinate 无本轮残留。中间方案的 Tauri 最后由 launcher 终止收尾，只有最终方案使用上述正常退出验收。

原生按窗口截图在本机返回 `could not create image from window`，未作为成功验收；原生预览内容取自真实 renderer DOM，视觉截图检查为前述浏览器矩阵。最后一次 heap 采样与应用正常退出相遇，返回 255；此前 loaded / view-cleared / clear-idle / disconnected 原生 heap 均成功，未把退出后的失败样本纳入分配结论。

本轮确认修复读取线程池依赖、重复创建消息行和二进制预览默认格式；历史退出挂起的原始触发条件、上述剩余原生分配和更长时段行为继续保留。没有增加强制 GC、周期重载或自动重启。
