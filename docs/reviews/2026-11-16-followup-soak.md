状态：长跑、协议与浏览器补测通过；最新构建的原生电表界面补验待桌面解锁。

本轮承接 `2026-11-16-memory-and-exit.md`，重点复核消息行复用后暂停、滚动、详情、端点切换、清空与恢复跟随的组合行为，并扩大原生协议回归范围。源码基于 main / `1df2099`，保留此前未提交修复；测试使用当前工作目录构建的两个 renderer。

- macOS arm64，Node 26.13.0，Electron 43.1.0，真实 Tauri WKWebView。
- 仅本地回环与独立 PTY、独立应用 identifier / Electron profile / SQLite；不接用户设备或生产网络。

- 持续互发中反复暂停阅读、检查原位置和未读提示、冻结详情、恢复跟随、切换三个端点、清空视图；跟随状态下另检查详情打开后继续收包再关闭。
- 最后独立逐条检查 SQLite：字节、序号、重复/遗漏、跨端按连接的顺序哈希、完整性与外键。

## 驱动修正与测试补充

初次原生试跑中，“回到最新”后 Tauri 距底部 18px 并显示暂停。事件跟踪发现驱动直接调用 DOM `click()`，未像真实点击一样将焦点移到按钮，原消息预览继续持有焦点，WebKit 在行复用后自动把它滚入视口。驱动补齐点击前的焦点转移后，原产品代码的短测通过。

过程中尝试过跟随滚动调整，但未解决此驱动问题，已完整撤回；不能将该次尝试登记为产品修复。失败试跑及焦点诊断保留供复核。本轮没有据此修改产品滚动逻辑。

显示矩阵首次改用真实设置时，驱动尝试保存未改动的设置，而产品按设计禁用了保存；该轮 6 个超时保留在 `browser-targeted.log`。驱动改为未改动时取消、改动时保存，末次矩阵通过，未放宽产品断言或延长超时。

新增浏览器回归：持续收包时暂停、查看固定详情、接收新记录、关闭详情并回到最新，重复四轮。显示矩阵改为通过真实设置界面保存主题/字号、通过工具栏切换密度，核对编辑器字号和消息末行，而不只修改 DOM 样式。

## 已确认的界面问题及修复

全量浏览器首次运行 333 项，331 通过，2 项在 820px 竖屏入口失败：DL/T 645 主站电表配置表头提前变成两列，将启用控件放到了通信地址的下一行，垂直差 40px；同一场景的模拟器仍保持地址与启用同排。截图另确认主站抄读项的复选框被普通输入框的 30px 高度和全宽规则放大。

- 主站普通输入框样式排除复选框，复选框单独固定 16px、零边距；文本输入使用继承字体。
- 两个电表表头在较宽窗口保持名称、地址、启用、删除同排；700px 以下均将名称独占一行，地址、启用和删除保持同排。
- 表头回归增加 680px 和普通/大字号检查，同时检查复选框尺寸；抄读项复选框另检查 16px 方形尺寸。

修改位于 `Dlt645Panel.vue` / `Dlt645SimulatorPanel.vue` 的局部样式，不改变采集、协议、保存或 WebSocket 消息逻辑。正在运行的 WebSocket 长跑加载的是修改前 renderer；最终构建后另补运行核对，不把该长跑称为最终电表样式的原生验收。

## 长跑交互、窗口与退出

每端各完成 65 轮暂停阅读/恢复、65 轮跟随中打开详情后继续收包再关闭、65 次端点切换及 65 次清空视图，合计记录 780 项操作结果。暂停时消息内容与阅读位置保持，详情不随复用行改变，恢复回到最新；二进制预览为 HEX。两端 47 次采样均为可见、未最小化且系统未锁屏，renderer 身份保持不变，最多挂载 32 条消息行，无页面错误或持久化告警。采样不等于证明每一刻都无遮挡。

各库 332,800 帧的原始字节、完整序号、重复/遗漏、按连接的跨端顺序哈希、SQLite integrity / foreign_key_check 全部通过。20 分钟负载使用 128-byte 混合文本/二进制包，包含广播与多个端点，约每端 275 条历史帧/秒；不代表带宽打满或所有协议均完成该时长长跑。

该轮正常请求退出 Tauri 宿主，`NSRunningApplication.terminate()` 返回 true，实际宿主在 137ms 内退出；Electron `app.close()` 完成且测试脚本退出 0。进程清理另核对，不将失败时强制收尾登记为正常退出。

## 自然内存观察

通过启动前后进程差集确认唯一新增 WebContent PID，保留完整原始进程资源。以下是相同两个 renderer 在同一进程会话的阶段采样；RSS 与 physical footprint 分列，不能混为“应用总内存”。

| 阶段 | Electron renderer RSS MiB | Tauri WebContent RSS MiB | Tauri WebContent footprint MiB |
| --- | ---: | ---: | ---: |
| 负载结束 | 362.59 | 585.47 | 187.27 |
| 保持连接静置 60s | 307.70 | 585.03 | 180.33 |
| 清空当前实时视图后静置 60s | 307.88 | 585.02 | 161.36 |
| 断开全部连接后静置 60s | 308.56 | 585.09 | 159.55 |

采样峰值 WebContent RSS 585.47MiB / footprint 250.17MiB。实际占用指标有所回落，RSS 仍驻留；本轮没有采集 retaining path，不能将剩余部分全部归为缓存，也不能宣布历史内存问题完全解决。本轮交互频率与此前基线不同，不直接作性能改善百分比比较。

## 边界

浏览器的两个入口共用 Chromium 与显式 fixture，不等于原生协议或安装包通过；原生无 GUI 协议检查也不等于相应协议完成本轮桌面长跑。STOMP 的 Rust 设置部分使用内存 fixture，Electron 设置部分为真实隔离 SQLite。

本轮没有覆盖 Windows/Linux 原生安装、实体串口、现场设备、生产 TLS 或签名更新。此前原生 Text / non-object 内存驻留与历史 CleanupHandles 退出挂起的唯一根因仍保留，有限长跑通过不能证明长期无泄漏。

证据位于工具工作区 `scratch/2026-11-16-linklab-followup-soak/`，含驱动、原始失败、逐阶段资源/窗口采样、隔离数据库和各项日志。本轮未提交、推送、打包或发布。
