# OPC UA / STOMP 多端点验收（2026-10-22）

## 本轮行为

添加端点可选择 OPC UA 客户端、STOMP 客户端或服务端，条目与 TCP/UDP 一起显示，支持筛选、重命名、删除及独立连接。每条协议端点持有自己的控制器；已访问面板保持挂载，切换保留会话、订阅、临时凭据和草稿。协议认证流量仍使用独立原生通道，不进入普通帧历史。

目录直接复用 OPC UA `opcua/profiles.json` 与 STOMP `settings.stompProfiles`，已有配置显示为端点；没有数据库迁移或 PKI 搬迁。STOMP 配置随工作区导入/导出；OPC UA 使用自身 JSON 导入/导出。每个运行时 OPC UA 同时最多 8 个会话（包含待建立），STOMP 原生会话最多 4 个。

配置操作按源串行，STOMP 与设置全量保存共用队列并重新读取最新存储。删除/导入/编辑使用各自持有的端点锁；删除等待断开，存储失败保留条目和可见错误。对仍在操作或连接中的端点不覆盖连接参数。关闭目录会释放所有已创建控制器。
